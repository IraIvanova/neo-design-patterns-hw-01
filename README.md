# Домашнє завдання до Теми Основи об’єктно-орієнтованого програмування

Навчальний проєкт з об’єктно-орієнтованого програмування. Бібліотека зберігає авторів, друковані й електронні книги, примірники та читачів. Вона дає змогу шукати книги за автором і переглядати доступні примірники.

## Структура проєкту

- src/models/ містить моделі бібліотеки та абстрактний клас AbstractBook.
- src/services/BorrowService.ts відповідає за позичання й повернення примірників.
- src/main.ts демонструє роботу бібліотеки.
- tsconfig.json містить налаштування компілятора TypeScript.

## Принципи ООП

- Інкапсуляція. Приватні поля зберігають внутрішній стан об’єктів. Геттери дають доступ до окремих значень для читання.
- Абстракція та наслідування. AbstractBook визначає спільні дані та метод getDescription(). Його успадковують класи Book і EBook.
- Поліморфізм. Друкована й електронна книги по-різному реалізують getDescription(). Опис електронної книги також містить URL.
- Агрегація. Library об’єднує авторів, книги, примірники та читачів.

## Запуск 
Для запуску проєкту потрібні Node.js і npm.
У кореневій директорії виконайте наступні команди:
```commandline 
npm ci
npx ts-node src/main.ts
```
